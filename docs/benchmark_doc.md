# Global Functions

## `benchmark(fn)`
Quick and simple benchmark. Runs function once and returns time spent.

**Required Arguments:**
  - `Value: fn`

**Returns:**
  - `Map: stats`

---

## `printBenchmark(name, stats)`
Given a name and stats from benchmark(), prints out a summary.

**Required Arguments:**
  - `String: name`
  - `Map: stats`
